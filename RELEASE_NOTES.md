# Media Session 0.1.0

First public release of Media Session for LoupixDeck.

- Show artwork, title and artist from the selected Windows media session.
- Press Now Playing to play or pause; assign Next and Previous separately.
- Choose ArtworkAndText, TextOnly or ArtworkOnly layouts.
- Optionally scroll long titles and artists.

Requires Windows 10 version 2004 or later, or Windows 11, and LoupixDeck 1.34.0 or later (Plugin SDK 1.26.0).

Download `mediasession-0.1.0-windows.zip` and install it from the LoupixDeck Plugins window. Enable the plugin for your device and assign Now Playing to a touch button.

The media source must publish a Windows media session. Artwork is available only when the source provides it. Spotify sometimes publishes no artwork; skipping to the previous or next track may restore it.
